# View trong MySQL

Bài làm CodeGym 395 trên cơ sở dữ liệu mẫu `classicmodels`.

File `view_practice.sql` thực hiện đầy đủ vòng đời của view `customer_views`: tạo, truy vấn, sửa bằng `CREATE OR REPLACE VIEW`, kiểm tra định nghĩa và xóa. Phiên bản đã sửa dùng `WITH CHECK OPTION` để mọi thay đổi qua view vẫn thỏa điều kiện `city = 'Nantes'`.
