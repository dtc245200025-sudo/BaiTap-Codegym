# Bài tập: Nhúng CSS vào trang HTML

Bài làm minh họa ba cách sử dụng CSS:

- `inline.html`: khai báo CSS bằng thuộc tính `style` trên phần tử.
- `internal.html`: khai báo CSS trong thẻ `<style>`.
- `external.html`: liên kết tới tệp CSS riêng `styles.css`.

Mở từng tệp HTML trên trình duyệt để so sánh cách tổ chức mã nguồn.
