# Thư viện giải phương trình bậc hai

Thư viện Java giải phương trình `ax² + bx + c = 0`, bao gồm đầy đủ trường hợp hai nghiệm, nghiệm kép, vô nghiệm, phương trình bậc nhất và vô số nghiệm.

## Đóng gói và chạy

```bash
mvn clean package
java -cp target/quadratic-equation-lib-1.0.jar com.codegym.Main
```
