# Sử dụng các hàm thông dụng trong SQL

Bài làm cho hoạt động CodeGym 382. File `queries.sql` gồm bốn truy vấn trên cơ sở dữ liệu `QuanLySinhVien`:

1. Đếm sinh viên theo địa chỉ bằng `COUNT` và `GROUP BY`.
2. Tính điểm trung bình từng sinh viên bằng `AVG`.
3. Lọc sinh viên có điểm trung bình lớn hơn 15 bằng `HAVING`.
4. Tìm đầy đủ các sinh viên đồng hạng có điểm trung bình lớn nhất bằng `ALL`.

Chạy file sau khi đã tạo và thêm dữ liệu cho cơ sở dữ liệu `QuanLySinhVien` ở các bài trước.
