# Bài tập: Định dạng văn bản với CSS

Trang bài viết minh họa các thuộc tính định dạng văn bản theo yêu cầu:

- `font-style` cho đoạn dẫn và câu trích dẫn.
- `text-align` để căn giữa tiêu đề và căn đều nội dung.
- `font-size` tạo phân cấp rõ ràng giữa tiêu đề và đoạn văn.
- `text-indent` thụt đầu dòng cho các đoạn nội dung.
- `color` tạo màu riêng cho tiêu đề, nội dung và điểm nhấn.

Mở `index.html` bằng trình duyệt để xem kết quả.
