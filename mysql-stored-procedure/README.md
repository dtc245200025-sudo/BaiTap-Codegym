# Stored Procedure trong MySQL

Bài làm CodeGym 393 trên cơ sở dữ liệu `classicmodels`.

File `stored_procedure.sql`:

1. Tạo `findAllCustomers()` để lấy toàn bộ khách hàng.
2. Gọi procedure bằng `CALL`.
3. Xóa và tạo lại procedure để chỉ lấy khách hàng có `customerNumber = 175`.
4. Hiển thị định nghĩa cuối cùng bằng `SHOW CREATE PROCEDURE`.
